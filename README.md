## 🚀 About the Project  

This is my **personal portfolio website** designed to showcase my **skills, projects, and achievements**.  
It acts as a digital resume and helps recruiters and developers learn more about me.

## ✨ Features  

- 🧑‍💻 About Me section  
- 📂 Projects showcase  
- 🛠️ Skills display  
- 📞 Contact section  
- 📱 Fully responsive design
